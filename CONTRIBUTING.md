# Contributing

## Suggest a prompt

Open an issue with the **Suggest a prompt** template. You do not need to edit JSON or the generated README.

Please provide:

- The prompt text exactly as the creator published it.
- A link to the original post and the creator's name or handle.
- The input image requirements, if any.
- A result image link, if the creator published one.
- A short explanation of what the prompt does and any other tools used in the workflow.

We review attribution, source quality and whether the prompt adds a distinct use case before inclusion. A suggestion is not automatically accepted. Do not infer prompt text from an output image or submit a repost when the original source is available.

## Corrections and removals

Open an issue identifying the prompt and the requested correction, attribution change or removal. Include the original source where possible. Do not upload private material or third-party work you are not allowed to share.

## Pull requests

`README.md` is generated from a privately maintained catalog. Please suggest prompt additions and content corrections through issues instead of editing the generated README directly. Improvements to contribution instructions and issue templates are welcome. This public repository contains no raw dataset, discovery notes or build tooling.
